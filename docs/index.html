Documentation

A reference for RJNI's actual, verified behaviour — not a marketing summary. Every page below documents one real concept: what it does, its exact scope, how it fits the pipeline, and what's been verified against real, unmodified third-party code.

Status. RJNI has not yet shipped a packaged, publicly installable build. This documentation describes the tool's actual, verified pipeline and its intended external interface — not a binary you can currently download. See Getting started. To discuss early access, contact hello@rjni.dev.
